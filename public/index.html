HOW TO READ THE EVIDENCE

An honest measurement contract.

Coverage ≠ accuracy

A returned candidate is coverage. Correctness requires all supplied independent address fields and coordinate tolerances to match. Unlabelled cases never enter automated accuracy.

Errors stay in the denominator

Labelled request failures count as incorrect. Explicit no-match controls can be correct without a candidate. A high provider confidence is not a calibrated probability of correctness.

Separate evidence from judgement

Manual top-candidate acceptance is separate from automated accuracy. Fixture data proves the workflow, not Azure efficacy. Agree business targets before drawing conclusions.
