EVALUATION METHOD

Metrics and limitations.

Coverage and accuracy differ

Coverage counts returned candidates. Correctness requires all supplied reference address fields and coordinate tolerances to match. Cases without expected answers are excluded from automated accuracy.

Request errors count as failures

Request errors for cases with expected answers count as incorrect. No-match test cases can be correct without a candidate. The provider confidence value is not a verified probability of correctness.

Manual review is a separate metric

Manual acceptance of the top candidate does not change automated accuracy. Simulated responses test the workflow, not Azure Maps accuracy. Agree acceptance thresholds before evaluating results.
